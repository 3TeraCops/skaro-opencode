# Живая карта Chatballs: визуальное превью

Дата: 21.10.2026. Превью подготовлено по прямому поручению владельца и записи
«Запись 2026-10-20 225209.mp4», затем уточнено его поправками. Этот документ
описывает автономный визуальный артефакт на принятой C4; полнофункциональный
раздел дополнительно использует индекс кода/документов и пошаговый проигрыватель.
Статус реализации и проверки продукта — в [плане](project-graph-plan.md).

## Данные

Источник — принятая C4 Chatballs, редакция 2: блок `skaro-c4` в
`.skaro/architecture.md`, прочитанный штатным `docs.read` без изменения проекта.
Состав сверяется с `.skaro/c4/model.json`:

- 140 элементов в состоянии `current`;
- 238 явных текущих отношений C4;
- 41 дополнительная структурная линия из существующих `parent` и
  `deployment.instances`; эти линии не обозначают вызовы и не несут частиц;
- всего на карте 279 линий; элементы `planned` в этом превью исключены.

Названия, связи, пути исходников и варианты динамических представлений берутся
из модели. Выбор сценария подсвечивает его связи внутри всей карты.
Это не пошаговый проигрыватель целевой функции и не фактический поток запросов.

## Визуальное поведение

Вся карта видна сразу. Подсистемы пространственно разделены; размер узла зависит
от числа связей. Исходная раскладка вычисляется в worker, затем узлы мягко движутся
около устойчивых позиций. Камера вписывает карту с запасом для крайних подписей.
На общем масштабе подписи разрежены; у главного узла каждой подсистемы подпись
сохраняется постоянно. Подробности доступны через поиск и выбор.

Частицы одновременно проходят по явным направленным отношениям. Наведение
подсвечивает окружение узла и ослабляет остальные связи. Выбор открывает настоящий
`C4Details`; поиск перемещает камеру к найденному элементу. Есть раздельные
переключатели движения/частиц, пауза, масштабирование, вписывание и полный экран.
`prefers-reduced-motion` останавливает движение и частицы.

Оболочка захватывается из штатного Skaro: `TitleBar`, вкладки и навигация.
По окончательному указанию владельца C4 и граф находятся в основном меню после
задач. В дереве документов их нет; внутренняя группа документов — «Прочее».
C4 открывается отдельным разделом на общем `C4Scene`, граф — живой картой.
Используются настоящие `Select`, `TextField`, `Popover`, `SelectOption`, `Toggle`,
`IconButton`, `TooltipHost`, `C4CanvasTools` и `C4Details`. Контролы не скопированы
в CSS. Процент масштаба C4/графа редактируется в прежней надписи, без input.
Тумблеры примыкают к своим подписям; у графа иконка сети.

## Проверка и автономный HTML

Целевая проверка `e2e/graph-feature-live.spec.ts` запускает собранный Electron
со штатными main/preload, изолированным профилем и настоящим проектом Chatballs.
Mock API, временный сервер, генерация данных и агентные задания не используются.
Хэши C4 и архитектуры проверяются до и после, чтобы подтвердить отсутствие записи.

Проверяются переходы документ/граф/C4, количество текущих узлов, вписывание,
движение/пауза, поиск с путём к коду, сценарий, изменение размера, полный экран,
reduced motion и отсутствие ошибок renderer. Общий вид и выбранные состояния
сохраняются на снимках и проверяются визуально.

`e2e/graph-preview-live.spec.ts` отдельно проверяет автономный HTML в Chromium
штатного Electron. Автономный `chatballs-graph.html` содержит отрисованную оболочку,
её стили/шрифты и тот же скомпилированный компонент графа с worker.
Граф, поиск, сценарии и C4 интерактивны. Остальная оболочка является снимком,
без подключения IPC и без имитации работающего backend. Файл отдельно открывается
и проверяется в Chromium штатного Electron; это не проверка полноты приложения
в обычном браузере. Сборка HTML не запускает сервер.

Фоновый индекс работает в продукте, отдельно от этого автономного артефакта.
HTML не содержит полный индекс кода, backend и source-viewer; он предназначен
для сверки внешнего вида на принятой C4, а не для подмены проверки продукта.
