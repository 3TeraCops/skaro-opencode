# Skaro 2.2.0

## Что изменилось

- Добавлен раздел «Граф связей» на Sigma.js: общая карта архитектуры, кода
  и документации, движение узлов, частицы и подсветка взаимодействий.
- Добавлено воспроизведение сценариев C4: пауза, шаги, выбор шага и скорость.
- Реализованы поиск, фильтры, раскрытие групп, пути, анализ влияния и переходы
  к источникам с проверкой актуальности.
- Индекс строится в фоне после добавления/импорта проекта и обновляется
  при изменениях исходников, документов и принятой C4 без открытия раздела.
- C4 и граф вынесены в основное меню после задач. Внутренняя группа документов
  переименована в «Прочее».
- Масштаб графа и C4 можно редактировать прямо в надписи с процентом.
- Исправлены отступы сообщений об ошибке и конкуренция чтения/очистки кэша графа.

Граф показывает статически обнаруженные и архитектурные связи. Частицы
воспроизводят модель взаимодействий; фактический runtime-трафик не измеряется.
Неполное покрытие и неразрешённые ссылки отображаются явно.

Установщики Windows, macOS и Linux для x64/arm64 публикуются в GitHub Release.
Его описание содержит обязательную таблицу шести прямых ссылок.
Ограничения проверки графа: [протокол](project-graph-verification.md).
